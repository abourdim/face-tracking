Etsy 60-sec Video Shoot Card Face Tracking Kids · Script A

Pre-flight (90s)

  • Laptop + webcam on, lens wiped clean
  • Chrome/Edge open, index.html loaded
  • Clicked Start webcam once — face mesh confirmed
  • Kid framed: shoulders up, eyes centered
  • Soft front light on the face — no harsh backlight
  • Language/voice matches voiceover (EN / FR / AR)
  • Mirror toggle set the way you want on camera
  • micro:bit V2 charged (optional — for the BLE beat)
  • Phone in 9:16 on tripod, framing the laptop screen
  • Desk cleared — laptop + kid only
  • Script read once, under 55s
  • Phone silenced, siblings/dogs warned

Specs (memorise)

Length≤ 60s (aim 55s)
Aspect9:16 portrait
Res1080 × 1920 min
CodecMP4 / H.264 + AAC
Size< 100 MB
AudioMuted by default → captions mandatory
CoverFirst frame = thumbnail
HookFirst 3s decides the scroll

During recording

  • One scene per phase — don't cut every 2s
  • Switch on words, not mid-sentence
  • 1s pause on each expression (smile, wink, turn)
  • Eye contact with lens on CTA
  • Smile for final 3s — loop frame
  • If > 55s, re-cut

The 60-second arc — Script A

TimeSayDo / On-screen
0–3s "See, follow, smile — a face-AI lab in your browser, in 60 seconds." Kid close-up. Camera light on. Overlay: See · Follow · Smile.
3–10s "One page. Allow camera. That's it." Cut to laptop. Click Start webcam → allow → face mesh snaps on green.
10–20s "Smile — the numbers light up. Wink — it catches it." Smile → Smile chip glows. Wink → Left wink fires. Numerics panel ticks.
20–30s "Turn your head — yaw, pitch, roll. 468 landmarks tracking you." Toggle Mesh → Contours → Points. Head turns; yaw number moves.
30–40s "Demo mode announces every move — twelve languages plus Auto." Flip Demo mode. Voice says "smile detected". Scroll voice menu.
40–50s "Optional: pair a micro:bit V2 — face data streams over Bluetooth." Click Connect micro:bit. Packet counter ticks. Mirror toggle flips view.
50–55s "Link below — lifetime updates, webcam is all you need." Face-cam. Eye contact with lens.
55–60s "See · Follow · Smile." Hold a smile. Logo + handle freeze. Loop frame.

After Stop

  • Watch once, eyes off script
  • Trim to 55s (iMovie / CapCut / DaVinci)
  • Burn in captions — centered below subject
  • Set first frame = strong still of the face mesh
  • Export MP4/H.264, < 100 MB
  • Upload · verify autoplay · phone + sound off
